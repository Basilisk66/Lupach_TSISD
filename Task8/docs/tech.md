# Техническая документация

## Архитектура проекта

Сервис состоит из трёх частей:

1. **Хранилище данных** — статические файлы расписания (см. «Источник данных»).
2. **REST API** — отдаёт остановки, отправления и рейсы в формате JSON. Контракт описан в `openapi.yaml`.
3. **Клиент** (веб-страница) — обращается к API. В рамках этой работы клиент не реализуется, документируется только его поведение (`docs/user.md`).


## Как просмотреть и «запустить»

Для проверки надо использовать Swagger UI (команды приведены в `README.md`).


## Ключевые модули (логическая декомпозиция)

- **Stops** — поиск остановок и получение карточки остановки.
- **Departures** — вычисление ближайших отправлений на остановке: берутся записи расписания с временем не раньше текущего момента, сортируются по возрастанию, ограничиваются параметром `limit`.
- **Trips** — получение рейса по идентификатору со списком остановок маршрута.

## Источник данных

Расписание хранится в формате, близком к GTFS (General Transit Feed Specification): отдельные сущности `stops`, `routes`, `trips`, `stop_times`. Источником служат данные городского перевозчика, обновляемые раз в сутки (ночью). Отдельный режим «в реальном времени» не поддерживается.

## Формат времени

- Все даты и время в API передаются по стандарту **ISO 8601** со смещением часового пояса, например `2025-03-14T08:14:00+03:00`.
- Часовой пояс сервиса: `Europe/Moscow`.
- Для рейсов, идущих после полуночи, в расписании допускается время вида `25:10`, как в GTFS. API приводит его к обычной дате и времени (следующие сутки, 01:10).
- Поле `minutesUntil` — целое число минут от текущего момента до отправления (округление вниз).

## Договорённости

- Базовый путь API: `/api/v1`.
- Идентификаторы остановок — строки вида `S-102`, рейсов — `T-25-0814`.
- Ошибки возвращаются в едином формате `{ "code": "...", "message": "..." }`.
- Коды ответов: `200` — успех, `400` — неверные параметры, `404` — объект не найден.

## Конфигурация и переменные окружения

Для будущей реализации предполагаются переменные:

| Переменная | Значение по умолчанию | Описание |
|-----------|-----------------------|----------|
| `PORT` | `8080` | Порт HTTP-сервера \
| `DATA_DIR` | `./data` | Каталог с файлами расписания |
| `TZ` | `Europe/Moscow` | Часовой пояс сервиса |
| `DEFAULT_LIMIT` | `5` | Число отправлений по умолчанию |
