# Задача 20: Расписание транспорта

**Студент:** Иванов И.И.

> Замените на свои фамилию и инициалы.

## Постановка задачи

Остановки и ближайшие рейсы. User: найти остановку, смотреть ближайшие. Tech: формат времени, источник данных. OpenAPI: остановки, рейсы по остановке, рейс по id, поиск остановки.

## Обзор проекта

«Расписание транспорта» — небольшой сервис, который показывает пассажиру ближайшие рейсы автобусов, трамваев и троллейбусов на выбранной остановке. Пользователь находит остановку по названию, открывает её и видит список ближайших отправлений. По каждому рейсу можно посмотреть полный маршрут с временем прибытия на каждую остановку.

В репозитории нет полноценного бэкенда: API описан спецификацией `openapi.yaml`, а работу сервиса можно имитировать mock-сервером (см. ниже).

## Как посмотреть спецификацию

Вариант 1 — Swagger UI в Docker:

```bash
docker run -p 8081:8080 -e SWAGGER_JSON=/spec/openapi.yaml \
  -v "$(pwd)":/spec swaggerapi/swagger-ui
```

Откройте http://localhost:8081.

Вариант 2 — онлайн: вставьте содержимое `openapi.yaml` на https://editor.swagger.io.

Вариант 3 — mock-сервер Prism (отвечает примерами из спецификации):

```bash
npx @stoplight/prism-cli mock openapi.yaml
```
